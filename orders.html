Incorrect attempts are limited. A project owner who controls application code and server keys can change these controls; this feature protects normal database and admin access.

History visibility & permanent deletion

Visibility periods start when an order is delivered or cancelled. A shared order is permanently removed from the application database only after both audiences' periods expire. If either period is 0, automatic permanent deletion waits indefinitely. Manual deletion of a finished order removes it for both audiences, including its items, code record and queued email records. Provider backups or already-sent emails have their own retention.

Personalised order emails

Available fields: {{customer_name}}, {{order_number}}, {{order_total}}, {{delivery_slot}}, {{address}}, {{order_items}}, {{cancel_reason}}, {{store_name}}, {{store_email}}, {{store_phone}}, {{order_url}}. Messages are plain text and safely formatted for email. Delivery codes cannot be inserted.
